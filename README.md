# Köyüm Mandıra - GitHub Pages
Profesyonel statik mağaza sitesi.
- index.html ana sayfa
- urunler.html ürün kataloğu ve kategori filtreleri
- sepet.html çalışan localStorage sepeti
- css/style.css tüm tasarım
- js/main.js ürünler + sepet + WhatsApp siparişi

GitHub Pages: repository Settings > Pages > Deploy from branch > main > / (root).
ÖNEMLİ: Gerçek WhatsApp numaranızı js/main.js içindeki `https://wa.me/` kısmına ülke koduyla yazın.
